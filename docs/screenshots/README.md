# Screenshots

App screenshots taken from the SalmonCV web dashboard.

## Naming Convention

`<page>-<description>.png`

Examples:
- `dashboard-overview.png`
- `dashboard-relay-controls.png`
- `camera-live-feed.png`
- `camera-detection-overlay.png`
- `settings-wifi.png`
- `settings-starlink.png`
- `power-shutdown.png`
- `counts-daily-chart.png`
- `counts-species-breakdown.png`

Use lowercase, hyphens between words, and `.png` or `.jpg` to match the original format.
